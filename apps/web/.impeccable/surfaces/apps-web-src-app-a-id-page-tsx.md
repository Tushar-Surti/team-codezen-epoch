# Workspace surface brief

**Scope:** Analysis Workspace (`/a/[id]`), the product's core Operate surface. Its world is the product world: Simulator, Hook Lab, Title Fit, Editor and Report inherit it, and the landing page extends it in Persuade mode.
**Audience and job:** a solo creator with a script or rough cut who must see, within 5 seconds, the biggest predicted drop and why, then fix it and see what the fix is worth. Evaluators (analytics experts) check every number.
**Constraints:** Studio vocabulary; no fabricated metrics (fixtures say synthetic); EN/HI/Hinglish text; WCAG 2.2 AA; reduced motion; MacBook Air M3 at 60 fps.
**Unresolved:** dark theme (later, derived from cover-stock navy); final product name.

## Direction contract

THESIS: The Workspace is a shooting script under revision. The curve and the script share one time axis, the script doctor's red pen marks where viewers leave and why, and every applied fix becomes a colored revision draft. Refuses the metric-card grid plus generic line chart.

OWN-WORLD: Bond-white ground #F7F8F5, carbon ink #17171A; navy cover-stock rail #1B2440 with brass-brad accents #B08D3C. Script-doctor red #D7261E only for drops and risk. WGA revision colors (Blue #9CC3E6, Pink #F2B8C6, Goldenrod #E2A72E, Green #A8D5A2) only for drafts and applied fixes. Courier Prime only for script text; one bilingual grotesque for all UI, with tabular figures. Hairline-crisp data marks; a 5-step severity ramp everywhere.

STORY: See the biggest cliff circled in red with its one-line why → open it to see the quoted lines, margin note and signals → apply the fix → a Blue draft redraws the curve with the viewers kept → export markers.

FIRST VIEWPORT: Navy rail (nav), left. Project bar on top: title, category and language, draft tabs White/Blue/Pink, engine switch, Export. Upper 8 columns: curve with typical band; biggest cliff circled red with a margin note. Right 4 columns: Intro 0:30, APV, AVD and viewers at payoff, set large. Below: registered lanes, then the screenplay-format script with red margin notes. The fix queue on the right holds the primary action, Apply.

SIGNATURE: Applying a fix prints the changed lines on that revision's color with a * in the margin. The curve morphs into the revision color while the deltas count up.

MOTION: Pen strokes draw in (DrawSVG); the curve morphs (MorphSVG); a selected flag lifts while other lanes quiet; UI transitions take 150–300 ms.

FORM: Revision Draft (shooting-script revision pages + the script doctor's red pen), #3 on the ordered list, seed 0e1cd9e2.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
